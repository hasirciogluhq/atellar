Atellar 1 control plane ve sınırsız sayıda agent node lardan oluşmaktadır.

## Control Plane

Control plane node ları yönetir regiser olan node lara container ataması yapar. Container durumlarını yönetir. IP dağıtır, Node lara ip route ekleme yapar.

## Agent Node

Control plane den aldığı işleri yapar. Containerları başlatır, durdurur, siler. Network ayarlarını yapar.
